# Pragya Shree | Personal Resume Website

A personal portfolio built with HTML and CSS for the Web Development mid-term project.
It presents my two academic paths: BBA in Digital Business and Entrepreneurship at IIM Bangalore,
and Chinese Language at Jawaharlal Nehru University.

**Live website:** [PASTE GITHUB PAGES LINK]

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure and content |
| `style.css` | All styling: fonts, colours, layout, responsive rules |
| `README.md` | Project description |

## Sections

Home, About, Education, Skills, Achievement, Mandarin Corner, Interests, Future Goals, Contact.

## CSS concepts used

- Google Fonts: Newsreader, Figtree and Noto Serif SC
- Colour palette stored as CSS variables (ivory, jade green, charcoal, vermilion)
- Element, class and ID selectors
- Flexbox for the navbar, hero and buttons
- CSS Grid for skill and interest cards
- Sticky navigation using `position: sticky`
- Media query at 860px for mobile layout

## Run locally

Download the files into one folder and open `index.html` in a browser. No installation needed.
